# 文献库全量索引（INDEX，层级 2）

项目独有文献库的完整入口（文献明细）。引用流程：**先读层级 1（INDEX_QUICK.md）判断主题覆盖 → 命中后在本文件按主题/PMID 定位 → 回溯对应批次 CSV 与检索策略记录**，全过程有迹可循，无需重复检索 PubMed。

## 使用说明

- **两级索引**：本文件为层级 2（全量明细）；层级 1 快速分类索引见 [INDEX_QUICK.md](INDEX_QUICK.md)。判断主题是否已覆盖时先读层级 1。
- 在本索引中按主题找到文献后直接引用（附 PMID），并在该批次 CSV 中核实元数据。
- 两级索引中确无相关文献时，才发起新的 PubMed 检索（经授权检索通道，见 CLAUDE.md「PubMed 访问方式」节：MCP → 本地 CLI → 官方 HTTP 接口，降级须在检索策略文件中登记），检索后必须同时更新 `INDEX_QUICK.md`、本文件与 `csv/`、`search_strategy/`（见 CLAUDE.md「文献检索记录与存档」节）。
- 批次命名规则：`日期_序号`，序号递增，历史记录不删除。
